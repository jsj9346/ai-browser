# idea

저장소 루트의 `idea.md`를 관리한다. 항목 형식은 그 파일 머리말에 있는 것을 따른다.

입력: $ARGUMENTS

## 무엇을 할지 고르기

- **비어 있음**: 전체 항목을 제목, 상태, 날짜로 짧게 보여 준다. 폐기된 항목은 개수만 알린다.
- **새 아이디어**: 아래 "추가"를 따른다.
- **찾기**: "~ 관련 아이디어 있었나"처럼 묻거나 검색어만 준 경우, 일치하는 항목을 보여 준다.
- **상태 변경**: 해당 항목의 `상태` 줄만 바꾼다. 어느 항목인지 모호하면 후보를 보여 주고 묻는다.

## 추가

1. `idea.md`를 읽는다. 파일이 없으면 머리말부터 새로 만든다.
2. 비슷한 항목이 이미 있으면 새로 만들지 말고, 그 항목에 합칠지 사용자에게 묻는다.
3. 파일 맨 아래에 항목을 붙인다. 날짜는 오늘, 상태는 `제안`으로 한다.
   - 제목은 내용을 알 수 있는 짧은 한국어 명사구로 쓴다.
   - 본문은 사용자가 말한 내용을 쓴다. 대화에 나온 이유나 맥락은 함께 적되, 사용자가 말하지 않은 설계나 범위를 지어내지 않는다. 내 의견을 남길 때는 `메모:`로 시작해 구분한다.
4. 추가한 제목을 한 줄로 알린다.

## 지킬 것

- 아이디어를 기록했다고 구현을 시작하지 않는다. 구현은 사용자가 따로 요청할 때만 한다.
- 커밋은 사용자가 요청할 때만 한다.
- 항목을 지우지 않는다. 그만둔 아이디어는 상태를 `폐기`로 바꿔 왜 그만뒀는지 남긴다. 삭제는 사용자가 명시적으로 요청할 때만 한다.
- 채택된 아이디어의 설계와 일정은 `docs/architecture.md`에 정리하고, `idea.md`에는 상태만 남긴다.
