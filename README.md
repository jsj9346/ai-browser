# neo-browser

개발자용 AI 전용 브라우저 프로토타입입니다. 패널에 할 일을 적으면 Claude가 페이지를 읽고 클릭, 입력, 이동을 수행합니다. Electron과 TypeScript로 만들고, Linux를 먼저 지원한 뒤 macOS로 넓힙니다. 설계는 [docs/architecture.md](docs/architecture.md)를 참고하세요.

## 이름

이름은 영화 〈매트릭스〉의 네오에서 따왔습니다. 사용자와 에이전트는 현실 세계에, 웹은 매트릭스에 대응합니다. neo-browser는 매트릭스로 통하는 수단이자 그 안에서 세계를 조작하는 도구입니다.

| 매트릭스 | neo-browser |
|---|---|
| 매트릭스(가상 세계) | 웹 |
| 잭과 하드라인(접속 통로) | 브라우저 자체 |

이름의 뜻은 두 가지입니다. 그리스어 neo는 "새로운"이고, Neo는 The One의 애너그램입니다. 약어 풀이는 **N**avigate, **E**xecute, **O**perate(탐색하고, 실행하고, 대신 운용한다)입니다.

## 실행

```bash
npm install
npm start
```

패널의 설정에 Anthropic API 키를 저장하고, 주소를 연 다음 할 일을 입력합니다.

Ubuntu 24.04처럼 비특권 사용자 네임스페이스를 제한하는 Linux에서는 Electron 샌드박스 도우미에 권한이 필요합니다. 샌드박스를 끄고 실행하지 마세요.

```bash
sudo chown root:root node_modules/electron/dist/chrome-sandbox
sudo chmod 4755 node_modules/electron/dist/chrome-sandbox
```

## 안전장치

- 작업 페이지는 메모리에만 있는 전용 세션과 샌드박스에서 실행되며, 앱 기능에 접근할 수 없습니다.
- 작업 페이지는 사용자가 연 사이트와 승인한 호스트로만 통신합니다. 차단된 호스트는 패널에 표시되고, 사용자만 허용할 수 있습니다.
- 앱 내부 코드도 허용된 CDP 명령만 보낼 수 있습니다.
- 비밀번호, 카드, 일회용 코드 입력란에는 입력할 수 없습니다.
- 결제, 삭제, 전송 같은 이름의 요소를 클릭하거나 양식을 제출하려면 승인이 필요합니다.
- 새 사이트로 이동하려면 사이트별로 승인이 필요합니다.
- 페이지 내용은 신뢰할 수 없는 데이터로 표시해 모델에 전달합니다.
- API 키는 메인 프로세스에만 두고 암호화해 저장합니다. 암호화할 수 없는 시스템에서는 저장하지 않습니다.

## 알려진 한계

- 로그인 흐름은 아직 없습니다.
- 호스트가 정확히 일치해야 통신할 수 있어, 여러 도메인을 쓰는 사이트는 패널에서 호스트를 하나씩 허용해야 합니다.
- 허용한 사이트로 데이터를 보내는 것은 막지 못합니다.
- 프롬프트 인젝션을 완전히 막지는 못합니다. 민감 동작 판별은 요소 이름의 키워드에 의존하므로, 페이지가 이름을 위장하면 승인 없이 클릭될 수 있습니다.
- iframe 내부 내용은 읽지 못합니다.
- 페이지가 새 창을 열면 같은 화면에서 이어서 엽니다. 팝업 방식의 로그인은 동작하지 않을 수 있습니다.
- 다운로드와 카메라, 위치 같은 권한 요청은 모두 거부합니다.

## 테스트

```bash
npm run typecheck
npm test
npm run e2e
npm run e2e:security
```

`npm run e2e:security`는 실제 작업 세션에서 격리와 전송 통제를 측정합니다. 인터넷 연결이 필요합니다. `https://example.com`을 실제로 열고, 대조용으로 `example.com` 하위의 임의 이름을 DNS로 조회합니다.

`npm run e2e`는 실제 Electron에서 테스트 페이지를 조작합니다. Anthropic API만 가짜 서버로 대체하므로 실제 모델의 작업 성공률은 검증하지 않습니다.
