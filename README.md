# AI Browser Agent

로그인된 브라우저 탭에서 작업을 대신 수행하는 Chrome 확장 프로토타입입니다. 사이드패널에 할 일을 적으면 Claude가 페이지를 읽고 클릭, 입력, 이동을 수행합니다.

## 실행

```bash
npm install
npm run build
```

1. `chrome://extensions`를 열고 개발자 모드를 켭니다.
2. "압축해제된 확장 프로그램을 로드합니다"를 눌러 `dist/` 폴더를 선택합니다.
3. 툴바의 확장 아이콘을 눌러 사이드패널을 열고, 설정에 Anthropic API 키를 저장합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/agent.ts` | 에이전트 루프와 Claude API 호출 |
| `src/tools.ts` | 모델이 쓰는 도구와 사용자 승인 절차 |
| `src/policy.ts` | 모델 판단과 무관하게 코드로 적용하는 안전 규칙 |
| `src/browser.ts` | `chrome.debugger`(CDP)를 통한 브라우저 조작 |
| `src/ax.ts` | 접근성 트리를 모델용 개요로 변환 |
| `src/sidepanel.ts` | 사이드패널 UI |

## 안전장치

- 비밀번호, 카드, 일회용 코드 입력란에는 입력할 수 없습니다.
- 결제, 삭제, 전송 같은 이름의 요소를 클릭하거나 양식을 제출하려면 승인이 필요합니다.
- 새 사이트로 이동하려면 사이트별로 승인이 필요합니다.
- 페이지 내용은 신뢰할 수 없는 데이터로 표시해 모델에 전달합니다.

## 알려진 한계

- 프롬프트 인젝션을 완전히 막지는 못합니다. 민감 동작 판별은 요소 이름의 키워드에 의존하므로, 페이지가 이름을 위장하면 승인 없이 클릭될 수 있습니다.
- 링크 클릭으로 다른 사이트에 가는 경우, 승인 창은 요청이 전송된 뒤에 뜹니다. URL에 데이터를 실어 내보내는 것까지는 막지 못합니다.
- iframe 내부 내용은 읽지 못합니다.
- API 키가 브라우저 프로필에 암호화 없이 저장됩니다. 다른 사람에게 배포하려면 키를 보관하는 백엔드가 필요합니다.
- 패널을 닫으면 진행 중인 작업이 멈춥니다.

## 테스트

```bash
npm run typecheck
npm test
npm run e2e
```

`npm run e2e`는 실제 Chromium에 확장을 올려 테스트 페이지를 조작합니다. Anthropic API만 가짜 서버로 대체하므로 실제 모델의 작업 성공률은 검증하지 않습니다. Playwright의 Chromium이 필요합니다.
